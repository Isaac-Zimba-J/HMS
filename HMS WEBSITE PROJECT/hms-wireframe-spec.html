PERFORMANCE NOTES FOR DEVELOPER
  • Use backdrop-filter: blur() sparingly — only on the navbar. Overuse causes performance drops on low-end devices.
  • Lazy-load all images. Serve WebP format with PNG fallback.
  • Preconnect to Google Fonts: <link rel="preconnect" href="https://fonts.googleapis.com">
  • IntersectionObserver callbacks should unobserve() elements after they animate to avoid redundant calls.
  • The grid background and noise overlay use position:fixed — ensure they are below all content via z-index: 0 and pointer-events: none.
  • Counter animation uses requestAnimationFrame with easeOutCubic: 1 - Math.pow(1 - progress, 3)
